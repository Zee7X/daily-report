# Daily Report Review Skill

Triggers on `/daily-report-review`.

## Execution Steps

### 1. Collect Full Diff

```bash
git diff
git diff --cached
git log --since="today 08:00" --oneline -p
```

Combine all uncommitted and committed-today changes into a reviewable diff.

### 2. Analyze Each Changed File

For every file in the diff, evaluate:

- **Correctness** — does the logic match the apparent intent?
- **Naming** — are variables, functions, and components named clearly?
- **Side effects** — any unintended mutations, missing cleanup, or missing error handling?
- **Type safety** — TypeScript type gaps, any `as any`, missing return types
- **Performance** — unnecessary re-renders, missing memoization, expensive operations in render
- **Duplication** — code that already exists elsewhere in the codebase

### 3. TypeScript Errors (if applicable)

```bash
npx tsc --noEmit
```

### 4. Security Spot-check

Flag any obvious security concerns: exposed secrets in code, unsafe HTML injection,
missing input sanitization, unvalidated user input reaching sensitive operations.

## Rules

- Be specific — reference actual line content, not generic advice.
- Be constructive — every critique must include a concrete suggestion.
- Prioritize high-impact issues over style nits.
- If there are no changes to review, output: `"Nothing to review — no local changes detected today."`
