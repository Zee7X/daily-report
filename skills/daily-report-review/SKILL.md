# Daily Report Review Skill

Triggers on `/daily-report-review`.

## Execution Steps

### 1. Collect Diff

```bash
git diff
git diff --cached
git log --since="today 08:00" --oneline -p
```

Aggregate all changes made today into an inspectable diff.

### 2. Code Analysis Criteria

Evaluate each modified file across the following dimensions:

- Correctness: Does the implementation satisfy intended logic and handle edge cases?
- Naming: Are symbols, files, and functions domain-accurate and descriptive?
- Side Effects: Are there unhandled exceptions, dangling listeners, or state leaks?
- Type Safety: Are types explicit, sound, and free of loose assertions?
- Performance: Are there unnecessary allocations, expensive recalculations, or redundant renders?
- Architecture: Does the change respect existing conventions without speculative layers?

### 3. Type Checking

```bash
npx tsc --noEmit
```

### 4. Security Audit

Check for exposed secrets, unsafe string interpolation in queries/markup, missing sanitization, or unvalidated inputs.

## Guidelines

- Reference exact lines and symbols rather than generic advice.
- Every identified issue must be accompanied by an actionable fix.
- If no changes are detected, write: "No local changes detected today."
- Avoid decorative icons and emotional commentary.
