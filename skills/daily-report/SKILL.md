# Daily Report Skill

Triggers on `/daily-report`.

## Execution Steps

### 1. Extract Today's Session History (08:00–17:00)

Scan the active Antigravity session for all prompts and responses today.
Identify:
- Features or logic being built
- Components / modules most touched
- Bugs fixed or problems resolved
- Architecture or design decisions made

### 2. Run Git Commands

Execute the following in the current working directory:

```bash
git status --short
git diff --stat
git log --since="today 08:00" --oneline
```

- `git status --short` → which files were modified, added, or deleted
- `git diff --stat` → line-change summary per file
- `git log --since=...` → any local commits made today

If git is unavailable or the directory is not a repo, skip and mark as "N/A".

### 3. Run Type Check (Optional)

```bash
npx tsc --noEmit
```

Record "Clean (0 errors)" or list the errors found.

## Rules

- If no file changes are detected: display `"No local file changes detected today."`
- If session history is empty: mark the section with `"No session history available."`
- Always display the date in the format: **Thursday, October 8, 2026**
- Use emoji sparingly — enough to aid readability, not decorative noise.
