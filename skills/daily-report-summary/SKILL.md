# Daily Report Summary Skill

Triggers on `/daily-report-summary`.

## Strict Rule: Read-Only Operation

This skill is **STRICTLY READ-ONLY**:
- **DO NOT edit, modify, create, or delete any source files.**
- **DO NOT invoke `replace_file_content`, `write_to_file`, or any file mutation tools.**
- Only inspect session history and git status. Output plain text summary into chat.

## Execution Steps

### 1. Collect Context (Read-Only)

Scan active conversation context and combine with repository-wide Git state (`git status`, `git log`). If multiple chat sessions were used today on this workspace, synthesize the overall outcome across threads. Identify core completed features, bug fixes, and active blockers.

### 2. Format Output

Draft a focused summary in first person. Limit to 3 to 5 sentences without tables or code blocks.

---

## Output Template

```markdown
# Daily Summary - [DATE]

[Concise paragraph of 3-5 sentences summarizing tasks completed today, ongoing work, and next steps for tomorrow.]

Target: Standup / Slack / Teams
Generated by Antigravity daily-report-summary skill
```

---

## Guidelines

- **NEVER edit or modify any workspace files.**
- Keep the output strictly under 5 sentences.
- Do not paste raw diffs or code blocks in summary view.
- Conclude with tomorrow's planned items.
- If no activity is recorded, write: "No activity recorded today between 08:00 and 17:00."
