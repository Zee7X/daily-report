# Daily Report Summary Skill

Triggers on `/daily-report-summary`.

## Strict Rule: Read-Only Operation

This skill is **STRICTLY READ-ONLY**:
- **DO NOT edit, modify, create, or delete any source files.**
- **DO NOT invoke `replace_file_content`, `write_to_file`, or any file mutation tools.**
- Only inspect session history and git status. Output plain text summary into chat.

## Execution Steps

### 1. Collect Context (Read-Only)

Scan session context and run:

```bash
git status --short
git log --since="today 08:00" --oneline
```

Identify core completed features, bug fixes, and active blockers.

### 2. Format Output

Draft a focused summary in first person. Limit to 3 to 5 sentences without tables or code blocks unless requested by variant.

---

## Output Template

```markdown
# Daily Summary - [DATE]

[Concise paragraph summarizing tasks completed today, ongoing work, and next steps for tomorrow.]

Target: Standup / Slack / Teams
Generated by Antigravity daily-report-summary skill
```

---

## Command Variants

| Command | Format |
| --- | --- |
| `/daily-report-summary slack` | Casual, short format under 280 characters |
| `/daily-report-summary standup` | Structured list: Done, In Progress, Blockers |
| `/daily-report-summary email` | Formal business format with greeting and closing |

---

## Guidelines

- **NEVER edit or modify any workspace files.**
- Keep the default output strictly under 5 sentences.
- Do not paste raw diffs or code blocks in summary view.
- Conclude with tomorrow's planned items.
- If no activity is recorded, write: "No activity recorded today between 08:00 and 17:00."
