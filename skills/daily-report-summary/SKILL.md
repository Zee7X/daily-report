# Daily Report Summary Skill

Triggers on `/daily-report-summary`.

## Execution Steps

### 1. Gather Today's Context

Scan the session history and run:

```bash
git status --short
git log --since="today 08:00" --oneline
```

Identify:
- The main features or tasks completed
- Any significant bugs fixed
- Blockers, if any

### 2. Generate Compact Summary

Distill everything into **one paragraph** of 3–5 sentences, plain prose.
No bullet points. No markdown tables. No code blocks.

Tone: direct, professional, written in first person (e.g. "Today I worked on...").

---

## Output Format

```markdown
# ⚡ Daily Summary — [TODAY'S DATE]

[One paragraph, 3–5 sentences. Example:]

Today I completed the optimistic update flow for the `createOrder` mutation and fixed
the skeleton loading state on the dashboard page. I also refactored form persistence
to use localStorage, reducing re-fetch noise on navigation. TypeScript check is clean.
No blockers — will continue with the invoice PDF generation feature tomorrow.

---

**For:** Standup / Slack / Teams
**Generated by:** Antigravity — daily-report-summary skill
```

---

## Variants (Optional)

If the user appends a target platform, adapt the tone:

| Trigger | Tone |
|---------|------|
| `/daily-report-summary slack` | Casual, emoji OK, max 280 chars |
| `/daily-report-summary standup` | Structured: Done / Doing / Blockers |
| `/daily-report-summary email` | Formal, full sentences, salutation included |

---

## Rules

- **Never exceed 5 sentences** for the default variant.
- **No code or diffs** — this is human-readable prose only.
- If there is nothing to summarize: output `"No significant activity detected today between 08:00–17:00."`
- Always end with the next steps or what's planned for tomorrow.
